The upstream automatic criteria were:

- at least 200 issues over repository history
- at least 200 pull requests over repository history
- at least 200 forks
- not a fork
- commits in the collection interval from 2025-01-01 through 2026-07-31

The files are preserved as filter inputs. Manual or model-assisted
classifications belong in `output/` and are not committed.
