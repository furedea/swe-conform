# Repository Candidates

The four CSV files contain repositories selected by the revised upstream
quantitative filter.

| File             | Main language | Repositories |
| ---------------- | ------------- | -----------: |
| `java_new.csv`   | Java          |          658 |
| `js_new.csv`     | JavaScript    |          837 |
| `python_new.csv` | Python        |        1,271 |
| `ts_new.csv`     | TypeScript    |        1,593 |
| Total            |               |        4,359 |

The upstream automatic criteria were:

- at least 1,000 GitHub stars
- at least 200 issues over repository history
- at least 200 pull requests over repository history
- at least 200 forks
- not a fork
- commits in the collection interval from 2026-01-01 through 2026-07-31

This candidate set supersedes `docs/data/repository-candidates/` as the default
filter input. The earlier CSV files remain unchanged for provenance.
