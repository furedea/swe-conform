# ADR-0020: Balance guideline repositories by language

- Status: Accepted
- Date: 2026-08-17
- Supersedes: ADR-0012

In the context of constructing a benchmark from four language strata, facing
language imbalance when a single overall positive target stops all strata at
once, we decided for an equal repository quota per language that continues each
fixed random stratum order independently after human rejection, and against a
single cross-language target or redrawing rejected repositories, to keep the
final benchmark balanced and every replacement reproducible, accepting unequal
screening effort between languages and that this positive sample does not
estimate guideline prevalence.
